1. Login
2. Dashboard
3. Customers
4. Add Customer
5. Customer Details
6. Collect Payment
7. Advance Payment
8. Payment History
9. Day Collection Report
10. Search / Filter

13. Backup & Restore / Export & Import
14. Monthly Billing
15. Menu

## Excel import
The importer accepts headers such as:
- BOX ID
- CUSTOMER NAME
- PHONE NO / PHONE / MOBILE
- ADDRESS
- ZONE
- PACKAGE NAME / PACKAGE
- PACKAGE COST / MONTHLY AMOUNT
- DUE AMOUNT / DUE / PENDING
- ADVANCE AMOUNT / ADVANCE
- STATUS
- CARD NO / SMART CARD
- MSO
- AGENT NAME
- AGENT PHONE
- SUBSCRIPTION

Existing BOX IDs are updated instead of duplicated.
